# 💰 Student Expense Tracker

A simple and user-friendly web application for managing and analyzing student expenses. The application allows users to securely register, log in, record expenses, edit or delete transactions, and view spending reports through interactive charts.

## 🚀 Features

- 🔐 User registration and login
- 👤 User-specific expense management
- ➕ Add new expenses
- 📋 View expense records
- ✏️ Edit existing expenses
- 🗑️ Delete expenses
- 🔎 Filter expenses by category and date
- 📊 Dashboard with expense summaries
- 📈 Category-wise spending reports
- 📅 Monthly and daily expense analysis
- 🥧 Expense distribution charts
- 💾 SQLite database for data storage
- 🎨 Clean and user-friendly Streamlit interface

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **SQLite**
- **Pandas**
- **Matplotlib**
